Sum up 20 November's world news in one image: a newspaper front page drawn in pure Python standard library. Lead story: Kyiv hit by 110+ missiles and 400 drones hours after the Trump-Xi-Putin peace declaration in Shenzhen. Also inside: Myanmar's reaction to the ICJ genocide ruling, the stock-market plunge into correction, the UK-EU reset deal in Brussels, strikes in Gaza, and Saudi defences stopping missiles after the PIF Tower hit.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Writes `out/entry.png` (1024x1024, deterministic: two runs write identical bytes). No network, no files read, no clock.
